Password security basics

What makes a strong password?

Length matters most. A long, random password, or a passphrase of several unrelated words, is much harder to guess than a short one with a few symbols. Avoid names, dates and keyboard patterns.

Why password reuse is dangerous

When one site is breached, attackers try the same email and password on other services. A unique password per account limits the damage to one account.

What is password entropy?

Entropy estimates how unpredictable a password would be if every character were chosen randomly, measured in bits using length × log2(pool size). It is an estimate: a pattern or a dictionary word can make real strength far lower.

What is a password breach?

A breach happens when a service's stored data is exposed. Passwords that appear in known breach data are tried first by attackers, so they should be replaced even if they look complex.

How does k-anonymity protect breach checking?

Your browser hashes the password and sends only the first five characters of the hash. The service returns all matching suffixes and your browser compares them locally, so the full password and full hash are never sent.

Why Base64 is not encryption

Base64 only changes how bytes are written as text. Anyone can reverse it without a key, so never use it to protect secrets.

Why MD5 and SHA-1 are not recommended

Both are fast and have known collision weaknesses. Fast hashes are also a poor choice for storing passwords; use a slow, salted password hashing function such as Argon2, scrypt or bcrypt.

Why password managers are useful

A reputable password manager creates and remembers a unique password for every account, so you only need to remember one strong master passphrase.

Why MFA matters

Multi-factor authentication adds a second proof, such as an authenticator app or a security key, so a stolen password alone is not enough to sign in.
