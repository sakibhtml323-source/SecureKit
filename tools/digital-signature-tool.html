Digital Signature Tool

Runs locallyFreeNo login

Paste a private key to sign or a public key to verify. Signatures are Base64. ECDSA uses the raw r||s encoding used by Web Crypto and JWS.

  • Never paste a production private key into any website you do not control. This page runs locally, but treat sample keys as disposable.

FAQ

Why does verification fail?

The message, key, hash or algorithm differs from the one used to sign. Even one changed character invalidates a signature.
