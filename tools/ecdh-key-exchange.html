ECDH Key Exchange

Runs locallyFreeNo login

Two parties each combine their own private key with the other's public key and get the same secret. The tool also derives a 256-bit key with HKDF-SHA-256.

  • Use the HKDF output as the key, not the raw shared secret. Key agreement alone does not prove who the other party is.

FAQ

Do both sides get the same secret?

Yes. A's private key with B's public key gives the same value as B's private key with A's public key.
