RSA-OAEP Encrypt / Decrypt

Runs locallyFreeNo login

Paste a public key (PEM or JWK) to encrypt, or a private key to decrypt Base64 ciphertext. Hash choices are SHA-256, SHA-384, SHA-512 and SHA-1.

  • RSA encrypts only small messages (about 190 bytes for RSA-2048 with SHA-256). For larger data, encrypt with AES and protect that key with RSA.

FAQ

How much can RSA-OAEP encrypt?

Key size in bytes minus twice the hash size minus 2. For RSA-2048 with SHA-256 that is 190 bytes.
