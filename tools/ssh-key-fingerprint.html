SSH Key Fingerprint

Runs locallyFreeNo login

Paste one public key line (ssh-ed25519, ssh-rsa or ecdsa) to get its fingerprint for comparing with a server or provider.

  • Only public keys are needed. Never paste a private key. A matching fingerprint confirms the key, not the person.

FAQ

Where do I find the fingerprint to compare?

Run ssh-keygen -lf on the key file, or check the fingerprint shown by your Git host or server on first connection.
