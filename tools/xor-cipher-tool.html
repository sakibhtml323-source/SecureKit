XOR Cipher Tool

Runs locallyFreeNo login

Enter data and a key to get hex output. The brute-force mode tries all 256 single-byte keys and ranks the results.

  • Repeating-key XOR is not secure encryption. Brute-force scoring suits English text and may miss other data.

FAQ

Is XOR encryption secure?

Only a truly random one-time key as long as the message is secure. A short repeating key is easy to break.
